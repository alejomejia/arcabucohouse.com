# Agent guidelines

## React / Next.js performance and patterns

When writing, reviewing, or refactoring React/Next.js code (components, data fetching, bundle size, or performance), follow the guidelines in **`.cursor/skills/react-best-practices/`**:

- **SKILL.md** — Category index and rule names (use when deciding which patterns apply).
- **AGENTS.md** — Full expanded guide (reference when implementing or doing a deep review).
- **rules/*.md** — Individual rules (reference a specific rule file when focusing on one pattern).

Only load the full guide or rule files when the task is relevant; use this pointer to know where to look.

## Web design and UI guidelines

When reviewing UI code, checking accessibility, auditing design/UX, or checking a site against web best practices, use the guidelines in **`.cursor/skills/web-design-guidelines/`**:

- **SKILL.md** — How to run a review: fetch the latest rules from the source URL, apply them to the specified files, and output findings in the format specified there.

Only load this skill when the task involves UI review, accessibility, or design/UX audit.
